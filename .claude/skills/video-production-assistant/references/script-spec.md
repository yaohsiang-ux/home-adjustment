# 臨床教學影片腳本規範與規格（video-production-assistant）

版本：1.0　日期：2026-10-16
依據：2026.10.16「生成式 AI 臨床教學影音製作實戰」工作坊教材（clinical-teaching-video-designer 核心指令）。凡標示【教材】者可直接追溯教材原文；標示【製作建議】者為本規格補充的製作慣例，可依單位需求調整。

---

## 1. 適用範圍
- 適用於由臨床教學黃金文本（2,500～3,500 字專文）轉譯而成的單人主講教學影片。【教材】
- 輸出平台：NotebookLM／Gemini 影音摘要，或人工錄製配音。平台無法控制講者人數或時長時，依平台功能調整，不保證精準結果。【教材】
- 不適用：雙主持人對談、戲劇化情境劇、臨床實作認證用影片。【教材】

## 2. 影片總體規格
| 項目 | 規格 | 依據 |
|---|---|---|
| 片長 | 5～6 分鐘 | 教材 |
| 講者 | 單一主講人敘述 | 教材 |
| 語言 | 繁體中文、臺灣臨床常用術語 | 教材 |
| 語氣 | 專業而易懂，不誇大戲劇性 | 教材 |
| 核心能力 | 每片聚焦一項核心能力，重點至多三個 | 教材 |
| 學習目標 | 三項，使用 Bloom 可觀察動詞 | 教材 |
| 開場 | 前 30 秒以情境問題吸引注意 | 教材 |
| 旁白字數 | 約 900～1,200 字（以 200 字／分鐘估算，上限對應 6 分鐘） | 製作建議 |
| 畫面比例 | 16:9；字幕安全區留邊 5% | 製作建議 |

## 3. 腳本結構（四模組）
時間碼為影音重點分配建議，不代表專文須完整口述。【教材】四模組的時間碼來自教材；片尾為製作建議，可併入模組四結語。旁白字數建議為製作建議，四段加總 910～1,160 字，以 200 字／分鐘估算落在 4.6～5.8 分鐘。

| 模組 | 時間碼 | 必要內容 | 旁白字數建議 |
|---|---|---|---|
| 一、引言與臨床痛點 | 0:00–1:00 | 情境問題開場（30 秒內）、教學對象與三項學習目標、為何重要 | 150～200 字 |
| 二、關鍵決策與病人安全機制 | 1:00–2:30 | 關鍵決策點、決策權衡、安全核對與閉環確認步驟 | 240～300 字 |
| 三、迷思破除與深度思辨 | 2:30–4:00 | 一個核心思辨問題、常見迷思與反轉、儀器數據與床邊觀察等兩難 | 240～300 字 |
| 四、實戰避坑與核心行動綱領 | 4:00–5:30 | 新手常見陷阱、可預防的安全行動、核心記憶點與簡潔結語 | 240～300 字 |
| 片尾（製作建議） | 5:30–6:00 | 適用限制、待查證項目、審查聲明 | 40～60 字 |

敘事主軸固定為：臨床情境 → 關鍵決策 → 迷思反轉 → 安全行動 → 核心記憶點。【教材】

## 4. 腳本文件格式
### 4.1 片頭資訊區（腳本首頁）
- 片名
- 教學對象與能力層級（PGY／住院醫師、實習醫學生、護理師／專責護理師、醫事職類、跨專業團隊 IPE）【教材】
- 專科主題與核心情境類別（急重症與應變、技術與安全、診斷推理、醫病溝通與倫理、系統韌性）【教材】
- 三項學習目標（辨識／評估、分析／擬定、溝通／執行或省思）【教材】
- 核心思辨問題（一題）【教材】
- 新手常見陷阱（一至二項）【教材】
- 版本號、撰寫者、審查臨床教師、審查日期【製作建議】

### 4.2 分鏡表欄位
每一段落一列，欄位如下：

| 欄位 | 說明 |
|---|---|
| 編號 | 模組-段落，例如 2-3 |
| 時間碼 | 起訖，例如 1:00–1:30 |
| 旁白 | 主講人口述全文，口語化、每句一個概念 |
| 畫面指示 | 投影片、示意圖、流程圖、字卡；描述內容而非指定真人影像 |
| 字幕／重點字卡 | 需出現在畫面上的關鍵字，至多三行 |
| 安全標註 | 「一般教學原則」或「需依院內資源／專科指引／病人狀況調整」【教材】 |
| 證據標註 | 來源，或標示「待查證」【教材】 |
| 情境標註 | 真實案例內容，或「教學模擬情境」【教材】 |

### 4.3 旁白撰寫規則
- 每段開頭先點出問題或決策，再給原則，最後給行動。【製作建議】
- 術語第一次出現時以一句白話說明；避免過量術語。【教材】
- 口述數值、劑量、時限時，必須有證據標註；無法查核者改為「依指引與院內規範」並標示待查證。【教材】
- 不以「看完影片即具備實作能力」作結；結語導向後續練習、督導或 SOP 查閱。【教材】
- 不責備個人；陷阱描述聚焦系統與可預防因素。【教材】

## 5. 醫學安全與去識別化規範
1. 不得虛構研究、指引、統計、藥物劑量、院內 SOP 或專家經驗。【教材】
2. 腳本中不得出現姓名、病歷號、完整生日、精確就診時間或其他可辨識病人資訊。【教材】
3. 真實案例不得自行補充關鍵病史、檢查數值或結局；必要新增情節須標示「教學模擬情境」。【教材】
4. 每個模組至少一項明確的病人安全行動。【製作建議】
5. 腳本須經臨床教師審查後才能正式使用。【教材】

## 6. 影音生成指令規格（輸出 B）
- 長度 200～350 字，可獨立貼入 NotebookLM／Gemini。【教材】
- 必含要素：繁體中文、單一主講人、專業而易懂、約 5～6 分鐘、前 30 秒情境問題、三項核心訊息、決策權衡、常見迷思、病人安全行動、簡潔結語。【教材】
- 必含禁止事項：避免雙人訪談、捏造事實、過量術語。【教材】
- 附註平台限制聲明。【教材】

## 7. 交付物與命名
| 交付物 | 格式 | 命名範例 |
|---|---|---|
| 腳本分鏡表 | Markdown 或 Word 表格 | `script_<主題代碼>_v1.0.md` |
| 影音生成指令 | 純文字，200～350 字 | `prompt_<主題代碼>_v1.0.txt` |
| 教師審查清單 | 勾選表 | `review_<主題代碼>_v1.0.md` |
| 黃金文本（輸入，非本 Skill 產出） | 2,500～3,500 字專文，由 clinical-teaching-video-designer 產生 | `article_<主題代碼>_v1.0.md` |

命名與版本規則為製作建議；主題代碼由單位自訂。

## 8. 審查清單（輸出 C）【教材】
- □ 臨床事實與指引已核對
- □ 案例去識別化
- □ 未新增未標示的事實
- □ 學習目標符合受眾
- □ 決策與安全步驟清楚
- □ 影音重點可在短時間理解
- □ 院內 SOP 與適用限制已審查

補充檢核【製作建議】：
- □ 片長估算在 5～6 分鐘內
- □ 四模組時間碼與旁白字數相符
- □ 每段皆有安全、證據、情境三項標註
- □ 生成指令字數在 200～350 字之間

## 9. 品質標準【教材】
內容準確、教學適切、情境真實、結構連貫、語句精簡。資訊不足時先問關鍵問題或清楚標註限制。
