# 影片輸出範本使用說明

三份範本對應規格中的三項交付物。每份都有 Markdown 與 Word 版本，內容相同。

| 範本 | 用途 | 何時填寫 |
|---|---|---|
| 01-script-storyboard | 腳本分鏡表，給錄製或人工配音用 | 訪談確認後、生成前先填片頭資訊區 |
| 02-generation-prompt | 200～350 字影音生成指令，貼入 NotebookLM／Gemini | 分鏡表完成後 |
| 03-review-checklist | 教師審查清單 | 正式使用前，由臨床教師填寫 |

## 使用流程
1. 複製 01 範本，改名為 `script_<主題代碼>_v1.0`，填片頭資訊區。
2. 依四模組逐段填分鏡表。每段的旁白、畫面指示、三項標註都要填，不可留空；無內容時填「無」。
3. 以旁白總字數估片長：總字數 ÷ 200 ≈ 分鐘數。超出 6 分鐘就刪減，而非加快語速。
4. 複製 02 範本，從分鏡表擷取三項核心訊息與開場問題，填成一段 200～350 字的指令。
5. 複製 03 範本交給臨床教師審查。七項教材檢核全部勾選後才可正式使用。

## 占位符規則
- 【　】內為待填內容，填完後把括號一併刪除。
- 「待查證」「教學模擬情境」「一般教學原則」「需依院內調整」為固定標註用語，請原樣使用，方便審查時搜尋。
- 範本不預填任何臨床事實、數值或劑量。
